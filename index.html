Supabase configuration

Configuration is accessible here to administrators, but the public Supabase URL and publishable key remain visible in browser source. Never paste a service-role or secret key here.

For production, embed the publishable connection values in the CONFIG object in the HTML before deployment. Database access is controlled by Supabase policies, not by hiding these values.
